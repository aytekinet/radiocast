# RadioCast Live 📻

A free, open-source, and ad-free web platform for listening to thousands of radio stations and podcasts from around the world. 

🔗 **[Live Demo](https://radiocastlive.vercel.app/)**

## ✨ Features

*   **No Ads, Completely Free:** Uninterrupted listening experience.
*   **Global Access:** Discover thousands of radio stations and podcasts globally.
*   **Resume Playback:** Smart memory to continue your podcasts exactly where you left off.
*   **Personalization:** Create custom playlists and save your favorite stations.
*   **Sleep Timer:** Automatically stops playback for night listeners.
*   **Customizable UI:** Dark and light mode support with various theme options.
*   **Low Data Mode:** Saves bandwidth for mobile or metered connections.
